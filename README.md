# catalogo-mock — static mock-test demo (NOT the real project)

Clickable demo of the Express Inventory & Lots Catalog buyer experience.
Fake data only (picsum placeholders, `TODO(HUMAN)` everywhere real values go).
No server, no database, no accounts, no secrets, no build step.

- Open `index.html` in any browser, or serve this repo via GitHub Pages.
- Seller WhatsApp number: typed into the on-page settings field (stored in
  your browser's localStorage). Default is a clearly-fake placeholder.
- Simulated admin: localStorage CRUD + photo file-picker.
- Source of truth: `feat/cat-b2` branch of `pi-workspace-core`
  (`documents/ideas/2026-10-24_CATALOG_MOCK_*`, 19/19 verify proof).

Built by the catalog team (Zena cat-lead + cat-b2), 2026-10-24.
